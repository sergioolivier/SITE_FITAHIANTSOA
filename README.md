À propos

FITAHIANTSOA est une entreprise malgache spécialisée dans l'importation et la distribution de matériel agricole (motoculteurs diesel Changfa et Hong Yuan, tracteurs, motopompes, décortiqueuses de riz, pièces détachées), qui évolue vers une marketplace plus large réunissant plusieurs secteurs : agriculture, tourisme durable, artisanat malgache, électronique, mode et matériel médical.

Ce dépôt contient le prototype du site web de la plateforme, pensé comme un écosystème numérique reliant clients, fournisseurs, employés, administrateurs et partenaires logistiques.

Fonctionnalités
Catalogue produits avec recherche et filtres (catégorie, prix, note, pays d'origine)
Fiche produit détaillée — galerie photo, caractéristiques techniques, avis, QR code
Panier et tunnel de commande en plusieurs étapes (adresse, paiement, confirmation)
Suivi de commande avec timeline de livraison
Espace client — favoris, compte, historique
Espace fournisseur — ajout de produits, suivi des ventes et des revenus
Espace employé — validation des produits, gestion des commandes et réclamations
Espace administrateur — statistiques, utilisateurs, finances, marketing
Espace partenaire logistique — gestion des missions de livraison

Technologies

Le site est un prototype entièrement autonome (React 18, sans étape de build) : toutes les images sont intégrées directement dans le fichier index.html, ce qui permet de l'héberger tel quel sur GitHub Pages, sans aucune dépendance externe à installer.

index.html   → l'intégralité du site (interface et données de démonstration)
assets/      → logo et visuels utilisés dans ce document
Lancer le projet en local

Aucune installation n'est nécessaire. Il suffit d'ouvrir le fichier index.html dans un navigateur, ou d'utiliser le lien de démonstration ci-dessus.

Statut du projet

Prototype de démonstration à données fictives. Les espaces professionnels (fournisseur, employé, administrateur, partenaire logistique) sont accessibles depuis la barre de navigation en haut du site.
